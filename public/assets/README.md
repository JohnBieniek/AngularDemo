# Public assets

- `brand/` contains shared identity assets, profile photography, and social previews.
- `documents/` contains downloadable documents such as the portfolio resume.
- `projects/` contains media grouped by portfolio project.
- `legacy/` contains retained static CSS and JavaScript that are not part of the Angular source tree.

Use lowercase kebab-case filenames for new assets and place project-specific media in
`projects/<project-slug>/`.
